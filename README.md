# Reel Studio

A slot machine win animator: set up a machine, sequence spin rounds,
preview the wins and export an editable After Effects project.

**Open the app:** https://eyalmrp.github.io/reel-studio-app/

No account or install needed; it runs in Chrome, Edge or Safari. Your
work is saved in your own browser (Project › Save project to share it).

This repository holds only the published page, built from a private
source repository. Changes made here are overwritten by the next publish.
